# UNIX
**UNIX | Uniplexed Information and Computing system**    
> uniplex : one data channel handles one data, multiplex: processing a various task in one line  

## 3 main feature
- Mutitasking  
> handling two or more task at the same time  
- Multi-user  
- Multithreading  
> what is this? : execution model where a single process runs multiple threads concurrently while sharing the process's allocated memory space  
> concurrency, parallelism  
>
> /  
> sharing resource  
> All threads within a process share the code, data, and heap memory segments  
> low overhead exchange : sharing heap data, low intervention of OS kernel  
> /  
> independent resource  
> Each threads maintains its own stack
