## 구조체  
### 자기참조구조체와 외부참조구조체  
#### 외부참조 구조체  
``` c
struct point {
  int x;
  int y;
}

struct student {
  char name [15];
  struct point* p;
};

int main(void) {
  struct student std1 = {"Kim", NULL };
  struct student std2 = {"Lee", NULL };

  struct point p1 = {10,20};
  struct point p2 = {30,40};

  std1.p = &p1;
  std2.p = &p2;
};
```
-> : 포인터가 가리키는 구조체의 멤버에 접근

### 연결 리스트에 새로운 노드를 삽입하는 순서
1. 삽입할 노드를 준비 (생성)
2. 새 노드의 데이터 필드에 값을 저장
3. 새 노드의 주소를 저장
4. 새롭게 삽입할 노드를 연결한다

### 기존에 연결되어있는 연결 리스트에 새로운 노드를 삽입    
1. 새로운 노드를 준비한다. (data를 집어넣는것은 아니다)   
새로운 주로를 가리키는 하나의 포인터변수를 선언    
[160] - |주소 160 [data | link]    
임시로 노드를 연결할 수 있게 만들어주는 새로운 헤더 노드라고 이야기 할 수 있다.     
----

2. 새로운 노드의 데이터 값을 저장     
[160] - |주소 160 [data (화) | link]   
----   

3. 새 노드의 필드중에서 link 에 값(주소)을 지정  
> 새 노드 입장(기준)에서   
prev [월 | 200] ----> next [금 | 300]  
      standard[화 | null] <- 새롭게 추가할 노드   

new 노드를 삽립할 자리에서 앞 노드의 링크 필드 값을 new  노드의 링크 필드에 저장하면 된다  
prev [월 | 200] ----> next [금 | 300] (200)   
      standard[화 | 200] ^   

-----   
  
4. 앞 노드에 새 노드를 연결   
> "월: 노드의 링크 필드에 new 노드의 값(포인터 new 가 가리키고 있는 새로운 주소)을 앞노드의 링크필드에 저장한다  
prev [월 | 170] ---- next [금 | 300] (200)  
      standard[화 | 200] (170)   

> 연결 자료구조는 "링크 필드의 포인터 값"에 대한 연산만으로 삽입 연..
